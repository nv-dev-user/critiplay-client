# Specifications

## Technical Stack

### Backend

[CritiPlay API](https://api.critiplay.com) is a REST API built with [Hono](https://hono.dev/) and [Supabase](https://supabase.com/).

### Database

The project uses [Supabase](https://supabase.com/database) as a database solution, which is built on top of PostgreSQL. It provides a scalable and reliable database for storing and managing data. It offers features like authentication, real-time subscriptions, and serverless functions.

### File Storage

The project uses [Supabase Storage](https://supabase.com/storage) for managing and serving files. It provides a secure and scalable solution for storing and retrieving files, such as images, videos, and documents.

### Hosting

The frontend, [CritiPlay Client](https://www.critiplay.com), is hosted on [Vercel](https://vercel.com/) and is built with [Nuxt 3](https://nuxt.com/). It provides a fast and responsive user interface for the CritiPlay platform.
